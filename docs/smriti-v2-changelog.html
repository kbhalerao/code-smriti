Identity

  • Document ids hashed the commit; re-ingest inserted a generation rather than overwriting one.
  • Identity now derives from location. 127,327 documents re-keyed, 7,222 superseded generations deleted, 11,733 parent links repaired.
  • 24,530 LLM-chunker regions moved from symbol_index to a new semantic_unit type.
  • Placeholder names (anonymous, arrow_function) and names not unique within a file now key on the line span. 21,055 symbols were affected: 12,084 arrow_function, 8,971 anonymous, ~1,300 real names.

Class extraction

  • Class extents ended at the first line of the body, placing classes under the significance threshold. Methods were unaffected.
  • Parser fixed 2026-08-14. 30,977 of 32,443 files carried the pre-fix result until backfilled.

Reconciliation

  • 19,197 symbols created, 6,300 stale ids removed, 6,072 salvaged without an LLM call, 16,594 file metadata records refreshed.
  • 230 files whose parse yields no significant symbols were skipped, not emptied.

Added

  • Rust parsing. .rs was in no extension list; a 52-file repository held four documents. Now 746 symbols, 621 significant.
  • Inspector at /smriti: 10 read endpoints, three-pane UI, gutter rail, nearest-neighbour panel, four-verdict judgment layer, stratified sampling.
  • Scripts: reembed_corpus, reconcile_symbol_documents, repair_missing_language, ensure_query_indexes, benchmark_embedding_models, benchmark_retrieval.
  • Six GSI indexes recorded and reproducible.

Fixed

  • Repository listing 12.3s → 0.077s. Aggregated 180,000 documents for counts already stored per repository; a partial index was unused until the query constrained its leading key.
  • Commit embeddings double-prefixed: two layers each prepended search_document:.
  • Retired Ollama EmbeddingGenerator was exported and would write vectors from another model. Now raises.
  • Judgments keyed on "unknown" when the caller authenticated by PAT.

Breaking

  • All vectors regenerated. Old and new embeddings of the same document score cosine 0.02.
  • Dimension checks cannot detect the change: 768d on both sides. An embedding_manifest is written last by the re-embed and checked at API startup.
  • Model, prefixing, dimensionality and batching consolidated into one module per service, from six call sites across two. Prefixing is model-specific and asymmetric: nomic takes literal prefixes on both sides, Qwen an instruction on the query side only. Wrong prefixing measured at −0.11 AUC.
  • Batching bounded by an attention budget (B × L²) as well as a token budget; sizing uses effective length rather than character count. 4.5 → 12.9 documents/s.
  • CoS cos_vector_index runs on the same model and requires the same re-embed.

Not included

  • Structural fingerprints, clone detection, cross-repository porting. Designed and benchmarked, not built.
